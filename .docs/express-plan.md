# Экспресс-план реализации MVP

## Цели MVP

Демонстрация базовой структуры сайта бренда и проверка визуальной концепции MVP.

MVP должен включать:
- Главную страницу, открывающуюся при первом переходе на сайт.
- Видео-блок на главной в формате слайд-шоу.
- Блок каталога под видео-блоком на главной (без полноценных карточек товаров на этом этапе).
- Отдельные страницы: главная, каталог, визуальное исследование.
- Рабочую навигацию между страницами.
- Визуальное направление, соответствующее философии бренда: метаморфозность и тишина.

---

## Шаги реализации
1. Подготовка структуры и маршрутизации
   - Создать базовую структуру страниц: `Home`, `Catalog`, `Visual Research`.
   - Настроить навигацию и переходы между страницами.
   - Проверить, что стартовой точкой является главная страница.

2. Реализация главной страницы MVP
   - Добавить верхний hero-блок с видео-слайд-шоу.
   - Ниже разместить секцию каталога в формате ленты.
   - Реализовать выразительную, но легкую верстку ленты без финальных карточек товаров.

3. Реализация страницы каталога
   - Создать отдельную страницу каталога как продолжение стилистики главной.
   - Подготовить layout под небольшой ассортимент и будущие товарные карточки.
   - Сохранить фокус на визуальной подаче и удобстве сканирования.

4. Реализация страницы визуального исследования
   - Сделать страницу в формате визуального дневника бренда.
   - Основной акцент отдать видео-материалам.
   - Добавить короткие текстовые подписи без перегрузки длинными описаниями.
   - Исключить стилистику "типичного архива" и "текстового блога".

5. Финальная проверка MVP
   - Проверить переходы между всеми страницами.
   - Проверить адаптивность на desktop и mobile.
   - Проверить соответствие базовой философии бренда и требованиям из `.docs/description.md`.

## Ресурсы и технологии
- Документ требований: `.docs/description.md`
- Правила проекта: `.docs/rules.md`
- Локальная среда разработки: Windows 11, VSCode, Git
- Медиа-материалы для видео-слайд-шоу и визуального исследования (временные заглушки или согласованный контент)
- Язык разработки: `TypeScript` (strict mode)
- UI-фреймворк: `React`
- Основной фреймворк проекта: `Next.js` (App Router)
- Маршрутизация страниц: встроенный роутинг `Next.js` (`/`, `/catalog`, `/visual-research`)
- Интернационализация (UI): `next-intl` для `ru/en`
- Стилизация: `Tailwind CSS` + CSS variables для дизайн-токенов
- Анимации: `Framer Motion` (переходы секций, появление блоков, анимации ленты)
- Видео и медиа: HTML5 video (`.mp4`/`.webm`), poster-превью, lazy loading
- Управление состоянием на этапе MVP: локальный state React (без глобального state manager)
- Данные на этапе MVP: статические данные/JSON-заглушки
- Пакетный менеджер: `pnpm`
- Git-практика: аннотированные теги `git tag -a`, фиксация релизных изменений в `.docs/CHANGELOGE.md`
- Backend/API на этапе MVP: не реализуется, фокус только на frontend-части и визуальной подаче

## Оценка времени и затрат
Оценка по этапам:
- Этап 1 (структура и маршрутизация): 0.5 дня
- Этап 2 (главная + видео-блок + лента каталога): 1 день
- Этап 3 (страница каталога): 0.5 дня
- Этап 4 (страница визуального исследования): 0.5–1 день
- Этап 5 (проверка и полировка MVP): 0.5 дня

Итоговая оценка MVP:
- Срок: 3–3.5 рабочих дня
- Команда: 1 frontend-разработчик
- Риски: задержка по контенту (видео/визуалы), доработки по визуальному тону после первого просмотра

Критерий готовности MVP:
- Доступны 3 страницы: главная, каталог, визуальное исследование.
- Главная открывается по умолчанию и содержит видео-слайд-шоу + секцию каталога ниже.
- Навигация между страницами работает стабильно.
- Визуальная подача соответствует описанной философии бренда.
